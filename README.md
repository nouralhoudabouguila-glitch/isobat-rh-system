# 🏢 ISOBAT HR Management System

A modern desktop Human Resources Management System developed for **ISOBAT** during my engineering internship.

The application aims to replace manual Google Sheets management with a centralized and user-friendly HR platform built with JavaFX.

---

## 📌 Project Overview

This application is designed to digitalize Human Resources operations within ISOBAT by providing an integrated solution for managing employees, attendance, leave requests, planning, and payroll administration.

The system is intended for internal use by Human Resources managers and team managers.

---

## ✨ Features

### 👥 Employee Management
- Add, edit and delete employees
- Employee profiles
- Department assignment
- Employee search and filtering

### ⏰ Attendance Management
- Daily attendance tracking
- Late arrivals
- Absences
- Overtime management

### 🏖 Leave Management
- Paid leave
- Sick leave
- Leave requests
- Leave validation
- Leave history

### 📅 Planning & Task Assignment
- Employee scheduling
- Task assignment
- Project/Dossier management
- Task status tracking (To Do • Doing • Done)

### 💰 Payroll Management *(In Progress)*
- Salary calculation
- Bonuses
- Deductions
- Overtime calculation
- Payroll generation

### 📊 Dashboard
- Employee statistics
- Attendance overview
- Leave statistics
- HR indicators
